# Módulos SDN para UrbIA

Este módulo contiene los controladores SDN implementados con Ryu, topologías virtuales y scripts para levantar y detener la red definida en la simulación multi-host.

## Estructura

- **controllers/**: controladores Ryu personalizados
- **topologias/**: definición de la red (opcional con Mininet)
- **scripts/**: ejecución y gestión de los controladores
